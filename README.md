# Julián Recarte - FullStack Web Developer Portfolio

Portfolio de Julián Recarte, desarrollador web FullStack. Multi-idioma (ES/EN/IT), con animaciones, scroll suave, dark mode y case studies por proyecto. En producción en [julianrecarte.dev](https://julianrecarte.dev/).

**Stack:** Astro 4 · Tailwind CSS 3 · GSAP (ScrollTrigger) · Lenis · Vitest + Happy DOM · Vercel.

```bash
npm install
npm run dev       # http://localhost:4321/es/
npm run build     # salida en dist/
npm run preview   # sirve dist/
npm test          # Vitest
```
